# Awesome DESIGN.md

プロジェクトに DESIGN.md をコピーして、AI エージェントに「このデザインに合わせてページを作って」と伝えるだけで、デザインに忠実なピクセルパーフェクトな UI が生成されます。


## DESIGN.md とは？

[DESIGN.md](https://stitch.withgoogle.com/docs/design-md/overview/) は Google Stitch が提唱した新しいコンセプトです。AI エージェントが読み込むことで、一貫した UI を生成するためのプレーンテキストのデザインシステムドキュメントです。

ただの Markdown ファイルです。Figma のエクスポートも、JSON スキーマも、特別なツールも必要ありません。プロジェクトのルートに置くだけで、AI コーディングエージェントや Google Stitch が UI の見た目をすぐに理解します。Markdown は LLM が最も読みやすいフォーマットなので、パースや設定は一切不要です。

| ファイル | 読み込む対象 | 定義する内容 |
|------|-------------|-----------------|
| `AGENTS.md` | コーディングエージェント | プロジェクトのビルド方法 |
| `DESIGN.md` | デザインエージェント | プロジェクトの見た目・質感 |

**このリポジトリは、実在するウェブサイトから抽出した、すぐに使える DESIGN.md ファイルを提供します。**

## DESIGN.md をリクエストする

[DESIGN.md をリクエスト](https://getdesign.md/request) から特定のウェブサイトの DESIGN.md をリクエストできます。あなただけに届けるプライベートリクエストにも対応しています。

## 各 DESIGN.md の中身

すべてのファイルは [Stitch DESIGN.md フォーマット](https://stitch.withgoogle.com/docs/design-md/format/) に拡張セクションを加えた形式に準拠しています：

| # | セクション | 記録する内容 |
|---|---------|-----------------|
| 1 | ビジュアルテーマ・雰囲気 | ムード、密度、デザイン哲学 |
| 2 | カラーパレットとロール | セマンティック名 + hex + 機能的ロール |
| 3 | タイポグラフィルール | フォントファミリー、全階層テーブル |
| 4 | コンポーネントスタイリング | ボタン、カード、入力、ナビゲーションと各状態 |
| 5 | レイアウト原則 | スペーシングスケール、グリッド、余白の哲学 |
| 6 | 深度・エレベーション | シャドウシステム、サーフェス階層 |
| 7 | Do's and Don'ts | デザインのガードレールとアンチパターン |
| 8 | レスポンシブ対応 | ブレークポイント、タッチターゲット、縮小戦略 |
| 9 | エージェントプロンプトガイド | クイックカラーリファレンス、すぐに使えるプロンプト |

各サイトには以下が含まれます：

| ファイル | 目的 |
|------|---------|
| `DESIGN.md` | デザインシステム（エージェントが読み込むもの） |
| `preview.html` | カラースウォッチ、タイプスケール、ボタン、カードのビジュアルカタログ |
| `preview-dark.html` | ダークサーフェス版の同カタログ |

### 使い方


1. サイトの `DESIGN.md` をプロジェクトルートにコピーする
2. AI エージェントに使うよう伝える
